# Review Checklist (Quality Gate)

Use this checklist before any document is marked **Approved** and moved to `docs/90_PUBLISHED/`.

## Content
- [ ] Title, date, version, owner are present
- [ ] Executive summary is clear and short
- [ ] Scope and objectives are measurable
- [ ] Target audience is defined and consistent
- [ ] Assumptions and constraints are explicit
- [ ] Budget numbers add up and match the narrative
- [ ] Timeline is feasible and matches resources
- [ ] Risks and mitigations are practical (not generic)
- [ ] Legal/safety/privacy needs are addressed (when relevant)

## Design / brand
- [ ] Uses the brand colors and typography from `docs/30_BRAND/BRAND_GUIDE.md`
- [ ] Uses consistent headings, spacing, and tables
- [ ] Logo placement and sizing consistent
- [ ] Charts are readable and labeled
- [ ] Arabic layout is RTL-correct (when AR)

## Platform readiness
- [ ] File name follows `DI_<DocCode>_<AR|EN>_<YYYY-MM-DD>_v<MAJOR.MINOR>.pdf`
- [ ] Document matches the Platform section scope
- [ ] “Latest approved” file uploaded to the Platform
