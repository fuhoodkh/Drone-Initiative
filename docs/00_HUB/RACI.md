- Project Manager: غيداء الجابري
- Marketing: روين العامري، رهام الغنبوصي، سلطان الحبسي

## RACI matrix (template)
R = Responsible (does the work)  
A = Accountable (final decision)  
C = Consulted (input)  
I = Informed (kept updated)

| Workstream | A | R | C | I |
|---|---|---|---|---|
| Proposal (`PROPOSAL`) | Project Manager | Program Lead | Partners | All |
| Sponsorship (`SPONSORSHIP`) | Project Manager | Marketing | Program Lead | All |
| Registration (`REGISTRATION`) | Project Manager | Registration Team | Training | All |
| Curriculum (`CURRICULUM`) | Program Lead | Training | FPV/Maintenance | All |
| Operations (`OPS`) | Project Manager | Logistics | Technical/Training | All |
| Safety (`SAFETY`) | Program Lead | Safety Owner | Civil aviation / venue | All |
| Media kit (`MEDIAKIT`) | Project Manager | Marketing | Program Lead | All |

> Replace placeholders after confirming the final appointed owners (Safety Owner, Registration Owner).
